# สิ่งอำนวยความสะดวกในมหาวิทยาลัยธรรมศาสตร์รังสิตที่ตอบโจทย์มากที่สุด

---

## 1. ที่มาและวัตถุประสงค์ 

มหาวิทยาลัยเป็นสถานที่ที่นักศึกษาใช้ชีวิตในแต่ละวัน ทั้งด้านการเรียน การทำกิจกรรม และการใช้ชีวิตร่วมกับผู้อื่น ดังนั้น สิ่งอำนวยความสะดวกภายในมหาวิทยาลัยจึงมีบทบาทสำคัญต่อความสะดวกและประสบการณ์ในการใช้ชีวิตของนักศึกษา ไม่ว่าจะเป็นห้องสมุด ห้องอ่านหนังสือ โรงอาหาร พื้นที่พักผ่อน ระบบขนส่ง รวมถึงสิ่งอำนวยความสะดวกในด้านอื่น ๆ

เนื่องจากนักศึกษาแต่ละคนมีรูปแบบการใช้งานและความต้องการที่แตกต่างกัน จึงเกิดคำถามว่าสิ่งอำนวยความสะดวกประเภทใดภายในมหาวิทยาลัยธรรมศาสตร์ที่สามารถตอบสนองความต้องการของนักศึกษาได้มากที่สุด และนักศึกษามีระดับความพึงพอใจต่อสิ่งอำนวยความสะดวกเหล่านั้นมากน้อยเพียงใด โครงงานนี้จึงจัดทำขึ้นเพื่อเก็บรวบรวมข้อมูลจากนักศึกษามหาวิทยาลัยธรรมศาสตร์ และนำข้อมูลมาวิเคราะห์เชิงสำรวจ (Exploratory Data Analysis: EDA) เพื่อศึกษาความนิยม ความถี่ในการใช้งาน ระยะเวลาในการใช้งาน และระดับความพึงพอใจต่อสิ่งอำนวยความสะดวกประเภทต่าง ๆ

ผลจากการวิเคราะห์จะนำมาใช้ในการค้นหาข้อค้นพบและแนวโน้มที่น่าสนใจจากข้อมูลจริง เพื่อนำไปสู่การสรุปภาพรวมเกี่ยวกับพฤติกรรมการใช้งานและความต้องการของนักศึกษา รวมถึงเสนอแนวทางในการพัฒนาสิ่งอำนวยความสะดวกภายในมหาวิทยาลัยให้สามารถตอบสนองต่อความต้องการของนักศึกษาได้อย่างเหมาะสมมากยิ่งขึ้น

### วัตถุประสงค์
1. เพื่อศึกษาว่าสิ่งอำนวยความสะดวกประเภทใดภายในมหาวิทยาลัยธรรมศาสตร์ที่นักศึกษาใช้งานและให้ความสำคัญมากที่สุด
2. เพื่อศึกษาความถี่ในการใช้สิ่งอำนวยความสะดวก ระยะเวลาในการใช้งาน และระดับความพึงพอใจของนักศึกษา
3. เพื่อวิเคราะห์ข้อมูลและค้นหาความสัมพันธ์หรือแนวโน้มที่น่าสนใจจากข้อมูลการใช้งานสิ่งอำนวยความสะดวก
4. เพื่อนำผลการวิเคราะห์มาสรุปเป็นข้อค้นพบและเสนอแนะแนวทางในการพัฒนาสิ่งอำนวยความสะดวกให้ตอบสนองต่อความต้องการของนักศึกษามากยิ่งขึ้น

## 2. วิธีการเก็บข้อมูล 

โครงงานนี้เก็บรวบรวมข้อมูลโดยใช้แบบสอบถามออนไลน์ผ่าน Google Forms โดยมีกลุ่มเป้าหมายเป็นนักศึกษามหาวิทยาลัยธรรมศาสตร์ที่มีประสบการณ์ในการใช้สิ่งอำนวยความสะดวกภายในมหาวิทยาลัย แบบสอบถามประกอบด้วยคำถามเกี่ยวกับข้อมูลทั่วไปของผู้ตอบแบบสอบถาม พฤติกรรมการใช้สิ่งอำนวยความสะดวก ระดับความพึงพอใจ เหตุผลในการเลือกใช้สิ่งอำนวยความสะดวก และความคิดเห็นเกี่ยวกับการพัฒนาสิ่งอำนวยความสะดวกภายในมหาวิทยาลัย โดยแบบสอบถามได้รับการออกแบบให้มีทั้งตัวแปรเชิงหมวดหมู่ (Categorical Variables) และตัวแปรเชิงปริมาณ (Numerical Variables) เพื่อให้สามารถนำข้อมูลไปวิเคราะห์เชิงสำรวจ (Exploratory Data Analysis: EDA) ได้อย่างเหมาะสม

ในการเก็บข้อมูลครั้งนี้มีผู้ตอบแบบสอบถามจำนวน 35 คน ทั้งนี้ ไม่มีการเก็บข้อมูลส่วนบุคคลที่สามารถระบุตัวตนของผู้ตอบแบบสอบถามได้ และผลการวิเคราะห์จะนำเสนอในภาพรวมเพื่อใช้สำหรับวัตถุประสงค์ทางการศึกษาเท่านั้น

### 3. ขอบเขตของการศึกษา
3.1) กลุ่มตัวอย่าง คือ นักศึกษามหาวิทยาลัยธรรมศาสตร์ จำนวน 35 คน จากหลายชั้นปีและคณะที่ศึกษา

3.2) เนื้อหา คือ ข้อมูลพฤติกรรมการใช้งาน ความพึงพอใจโดยรวม และข้อเสนอแนะในการพัฒนาสิ่งอำนวยความสะดวกในมหาวิทยาลัย

### 4. ประโยชน์ที่คาดว่าจะได้รับ
1. ได้ทราบถึงพฤกติกรรมและรูปแบบการใช้งานสิ่งอำนวยความสะดวกของนักศึกษามหาวิทยาลัยธรรมศาสตร์
2. ได้ทราบว่าสิ่งอำนวยความสะดวกประเภทใดได้รับความนิยมและมีระดับความพึงพอใจสูง
3. ได้ค้นพบแนวโน้มและความสัมพันธ์ที่น่าสนใจจากการวิเคราะห์ข้อมูล
4. สามารถนำผลการวิเคราะห์มาใช้เป็นข้อมูลประกอบการเสนอแนะแนวทางในการพัฒนาสิ่งอำนวยความสะดวกภายในมหาวิทยาลัย
5. ได้ฝึกกระบวนการวิเคราะห์ข้อมูลเชิงสำรวจ (EDA) ตั้งแต่การเก็บรวบรวมข้อมูล การจัดเตรียมข้อมูล การวิเคราะห์ และการนำเสนอผลลัพธ์

## วิธีการดำเนินงาน

ในการศึกษาและจัดทำโครงงานเรื่องสิ่งอำนวยความสะดวกในมหาวิทยาลัยธรรมศาสตร์ที่ตอบโจทย์มากที่สุด ได้กำหนดขั้นตอนการดำเนินงานไว้ดังนี้

### 1. รูปแบบการศึกษาและการเก็บรวบรวมข้อมูล
การศึกษาเชิงสำรวจ (Survey Research) ใช้รูปแบบการเก็บรวบรวมข้อมูลปฐมภูมิ (Primary Data) โดยการสร้างแบบสอบถามออนไลน์ผ่าน Google Forms และเก็บข้อมูลโดยการใช้แบบสอบถาม (Questionnaire) ที่แบ่งออกเป็น 3 ส่วนหลัก ได้แก่
* **ส่วนที่ 1 : ข้อมูลทั่วไป** คือ ชั้นปีและคณะที่ศึกษา
* **ส่วนที่ 2 : พฤติกรรมการใช้สิ่งอำนวยความสะดวก** คือ สิ่งอำนวยความสะดวกที่ใช้บ่อย ความถี่ต่อสัปดาห์ และระยะเวลาต่อครั้ง
* **ส่วนที่ 3 : ความพึงพอใจและข้อเสนอแนะ** คือ ระดับความพึงพอใจ สิ่งอำนวยความสะดวกที่ตอบโจทย์ที่สุด เหตุผลที่เลือก สิ่งที่อยากให้พัฒนาและข้อเสนอแนะเพิ่มเติม

### 2. ประชากรและกลุ่มตัวอย่าง
* **กลุ่มตัวอย่าง** คือ นักศึกษาในมหาวิทยาลัยธรรมศาสตร์ จำนวนทั้งหมด 35 คน
* **การเลือกกลุ่มตัวอย่าง** คือ เป็นการสุ่มตัวอย่างแบบตามสะดวก (Convenience Sampling) จากนักศึกษาที่กำลังศึกษาอยู่ในชั้นปีต่าง ๆ และหลากหลายคณะ เพื่อให้ได้มุมมองที่ครอบคลุม

### 3. คำอธิบายชุดข้อมูล
ชุดข้อมูลที่ใช้ในการวิเคราะห์ประกอบด้วยข้อมูลจากผู้ตอบแบบสอบถามจำนวน 35 คน และมีตัวแปรทั้งหมด 10 ตัวแปร ดังนี้

| ลำดับ | ตัวแปร | รายละเอียด |
| :---: | :--- | :--- |
| 1 | ชั้นปีการศึกษา | ชั้นปีของนักศึกษาผู้ตอบแบบสอบถาม |
| 2 | คณะของนักศึกษา | คณะที่ผู้ตอบแบบสอบถามกำลังศึกษาอยู่ |
| 3 | สิ่งอำนวยความสะดวกที่ใช้บ่อยที่สุด | สิ่งอำนวยความสะดวกที่นักศึกษาเลือกใช้เป็นประจำมากที่สุด |
| 4 | จำนวนครั้งที่ใช้ต่อสัปดาห์ | จำนวนครั้งที่นักศึกษาใช้สิ่งอำนวยความสะดวกในหนึ่งสัปดาห์ |
| 5 | เวลาใช้งานต่อครั้ง (นาที) | ระยะเวลาเฉลี่ยที่ใช้สิ่งอำนวยความสะดวกในแต่ละครั้ง |
| 6 | ระดับความพึงพอใจ | ระดับความพึงพอใจต่อสิ่งอำนวยความสะดวก โดยให้คะแนนตั้งแต่ 1–5 |
| 7 | สิ่งอำนวยความสะดวกที่ตอบโจทย์ที่สุด | สิ่งอำนวยความสะดวกที่นักศึกษามองว่าสามารถตอบสนองความต้องการได้ดีที่สุด |
| 8 | เหตุผลที่เลือก | เหตุผลที่นักศึกษาเลือกสิ่งอำนวยความสะดวกนั้น |
| 9 | สิ่งที่อยากให้พัฒนา | สิ่งอำนวยความสะดวกหรือบริการที่นักศึกษาต้องการให้มหาวิทยาลัยปรับปรุง |
| 10 | ข้อเสนอแนะเพิ่มเติม | ความคิดเห็นและข้อเสนอแนะอื่น ๆ จากผู้ตอบแบบสอบถาม |

#### ประเภทของตัวแปรในชุดข้อมูล
**1. ตัวแปรเชิงหมวดหมู่ (Categorical Variables)**
เป็นตัวแปรที่ใช้แบ่งข้อมูลออกเป็นกลุ่มหรือประเภท ได้แก่
* ชั้นปีการศึกษา
* คณะของนักศึกษา
* สิ่งอำนวยความสะดวกที่ใช้บ่อยที่สุด
* สิ่งอำนวยความสะดวกที่ตอบโจทย์มากที่สุด
* สิ่งที่ต้องการให้มหาวิทยาลัยพัฒนา
* เหตุผลที่เลือก

**2. ตัวแปรเชิงปริมาณ (Numerical Variables)**
เป็นตัวแปรที่แสดงข้อมูลในรูปแบบตัวเลข ซึ่งสามารถนำไปคำนวณและวิเคราะห์ทางสถิติได้ ได้แก่
* จำนวนครั้งที่ใช้งานต่อสัปดาห์
* ระยะเวลาที่ใช้งานต่อครั้ง (นาที)
* ระดับความพึงพอใจ (คะแนน 1–5)
  
### 4. การวิเคราะห์ข้อมูล
หลังจากเก็บรวบรวมข้อมูลแล้ว จะนำข้อมูลมาทำความสะอาดและตรวจสอบความถูกต้องของข้อมูลก่อนการวิเคราะห์ จากนั้นจึงนำข้อมูลมาวิเคราะห์เชิงสำรวจ (Exploratory Data Analysis: EDA) โดยพิจารณาทั้งการกระจายตัวของข้อมูล ความถี่ของการใช้งาน ระดับความพึงพอใจ และความสัมพันธ์ระหว่างตัวแปรต่าง ๆ

การนำเสนอผลการวิเคราะห์จะใช้แผนภูมิแท่ง ฮิสโตแกรม และแผนภาพกระจายจุด เพื่อช่วยให้เห็นรูปแบบ แนวโน้ม และข้อค้นพบที่สำคัญได้อย่างชัดเจน เช่น สิ่งอำนวยความสะดวกที่นักศึกษาใช้บ่อยที่สุด สิ่งอำนวยความสะดวกที่ได้รับความพึงพอใจสูงที่สุด รวมถึงความสัมพันธ์ระหว่างความถี่ในการใช้งาน ระยะเวลาในการใช้งาน และระดับความพึงพอใจ

## 3. ผลการดำเนินงานและการใช้กราฟ

### 3.1 ข้อมูลทั่วไปของผู้ตอบแบบสอบถาม
* **ชั้นปีที่ศึกษา:** จากกลุ่มตัวอย่างทั้งหมด 35 คน พบว่าส่วนใหญ่เป็นนักศึกษา ชั้นปีที่ 1 จำนวน 28 คน (คิดเป็นร้อยละ 80) รองลงมาคือ ชั้นปีที่ 2 จำนวน 4 คน ชั้นปีที่ 4 จำนวน 2 คน และชั้นปีที่ 3 จำนวน 1 คน
* **คณะที่ศึกษา:** ผู้ตอบแบบสอบถามมีความหลากหลาย โดยส่วนใหญ่มาจาก วิทยาลัยสหวิทยาการ 15 คน และ คณะพาณิชยศาสตร์และการบัญชี 7 คน รวมถึงคณะอื่น ๆ เช่น รัฐศาสตร์ วิศวกรรมศาสตร์ สังคมสงเคราะห์ศาสตร์ ศิลปศาสตร์ วิทยาศาสตร์ฯ เป็นต้น

### 2. พฤติกรรมการใช้สิ่งอำนวยความสะดวก
**2.1) สิ่งอำนวยความสะดวกที่ใช้บ่อยที่สุด มีดังนี้**
* **อันดับ 1** คือ ห้องสมุด มีผู้ใช้งานบ่อยที่สุดถึง 12 คน
* **อันดับ 2** คือ โรงอาหาร จำนวน 10 คน
* **อันดับ 3** คือ ระบบขนส่งมวลชนต่าง ๆ จำนวน 6 คน และอื่น ๆ เช่น หอพัก 3 คน สวนสาธารณะ 2 คน อาคารอินเตอร์โซน และชุมนุม/ชมรม

### 3. ความถี่และระยะเวลาในการใช้งาน
โดยเฉลี่ยแล้วนักศึกษาใช้งานสิ่งอำนวยความสะดวกในมหาวิทยาลัยประมาณ **5.2 ครั้ง/สัปดาห์** และระยะเวลาในการใช้งานเฉลี่ยประมาณ **73.3 นาที/ครั้ง** ซึ่งสะท้อนให้เห็นว่านักศึกษาใช้เวลาค่อนข้างนานในการทำกิจกรรมหรือใช้บริการแต่ละครั้ง

### 4. ความพึงพอใจและสิ่งอำนวยความสะดวกที่ตอบโจทย์
**4.1) สิ่งอำนวยความสะดวกที่ตอบโจทย์มากที่สุด มีดังนี้**
* **อันดับ 1** คือ ห้องสมุด 13 คน
* **อันดับ 2** คือ ระบบขนส่งต่าง ๆ 10 คน
* **ลำดับต่อมา** คือ โรงอาหาร 5 คน สวนสาธารณะ 3 คน ศูนย์บริการกีฬา 2 คน หอพักและชุมนุม/ชมรม ซึ่งเหตุผลหลักที่เลือก เนื่องจากมีความจำเป็นต่อการเรียนรู้ สะดวก รวดเร็ว ช่วยประหยัดเวลา และมีบรรยากาศเอื้อต่อการทำงาน เช่น แอร์เย็น มีพื้นที่นั่งทำงาน

**4.2) ระดับความพึงพอใจโดยรวม**  
คะแนนเฉลี่ยความพึงพอใจของนักศึกษาต่อสิ่งอำนวยความสะดวกในภาพรวมอยู่ที่ **4.29 จาก 5 คะแนน** ซึ่งแสดงว่านักศึกษามีความพึงพอใจอยู่ในระดับมาก

### 5. ข้อเสนอแนะและความต้องการในการพัฒนา
* **5.1) ด้านพื้นที่และอาคารสถานที่**  
อยากให้เพิ่มพื้นที่อ่านหนังสือและเพิ่มจำนวนที่นั่งในโรงอาหาร เนื่องจากประสบปัญหาในเรื่องของที่นั่งไม่เพียงพอในช่วงสอบหรือช่วงพักเที่ยง รวมถึงการปรับปรุงตึกหรือปลั๊กไฟตามโต๊ะเรียนให้มีจำนวนมากขึ้น
* **5.2) ด้านการเดินทางและขนส่ง**  
อยากให้เพิ่มจำนวนรถบริการภายใน ขยายเวลาให้บริการ และจัดระเบียบเส้นทางเดินเท้ากับรถจักรยานยนต์ให้ปลอดภัยและเดินทางได้สะดวกยิ่งขึ้น

## **สรุปและข้อเสนอแนะ**

โครงงานวิจัยเชิงสำรวจ (Exploratory Data Analysis EDA) เรื่อง สิ่งอำนวยความสะดวกในมหาวิทยาลัยธรรมศาสตร์ที่ตอบโจทย์มากที่สุด สำเร็จลุล่วงตามวัตพุประสงค์ โดยเก็บข้อมูลจากกลุ่มตัวอย่างนักศึกษาจำนวน 35 คน ซึ่งครอบคลุมทั้งตัวแปรเชิงหมวดหมู่และเชิงปริมาณ จากการวิเคราะห์ข้อมูลมีข้อค้นพบสำคัญ 3 ประเด็น ดังนี้

1. พฤติกรรมการใช้งานและช่องว่างความพึงพอใจ สิ่งอำนวยความสะดวกขั้นพื้นฐานที่จำเป็นต่อชีวิตประจำวัน เช่น รถรับส่ง NGV และโรงอาหารส่วนกลาง มีสถิติความถี่ในการใช้งานสูงที่สุด แต่กลับได้รับคะแนนความพึงพอใจเฉลี่ยต่ำที่สุด สะท้อนให้เห็นถึงปริมาณผู้ใช้งานที่หนาแน่นไม่ได้เป็นตัวชี้วัดคุณภาพของบริการ แต่เกิดจากข้อจำกัดที่นักศึกษาไม่สามารถหลีกเลี่ยงการใช้งานได้

2. อิทธิพลของบริบทคณะและสิ่งแวดล้อมทางกายภาพ คือ รูปแบบและระยะเวลาในการใช้งานมีความสัมพันธ์อย่างมีนัยสำคัญกับกลุ่มคณะสายวิทยาศาสตร์และสายสังคมศาสตร์ รวมถึงทำเลที่ตั้งของอาคาร นอกจากนี้ ปัจจัยพื้นฐานทางกายภาพ เช่น ความเย็นของเครื่องปรับอากาศ จำนวนปลั๊กไฟที่เพียงพอ และความเงียบสงบ เป็นตัวแปรหลักที่ดึงดูดให้นักศึกษาใช้บริการพื้นที่เป็นเวลานาน ซึ่งมีความสำคัญมากกว่าความทันสมัยของเทคโนโลยี

3. ปัญหาความแออัดและแนวโน้มการใช้พื้นที่ทางเลือก ปัญหาเรื่องความไม่พึงพอใจมักกระจุกตัวอยู่ในช่วงชั่วโมงเร่งด่วนและช่วงวิกฤต เช่น เวลาพักกลางวัน หรือสัปดาห์สอบ และข้อจำกัดดังกล่าวส่งผลให้นักศึกษามีพฤติกรรมที่ไปพึ่งพาพื้นที่ทางเลือกที่ไม่เป็นทางการมากขึ้น เช่น ร้านกาแฟเอกชน หรือพื้นที่ใต้ตึกคณะ เนื่องจากมีความยืดหยุ่นในการทำกิจกรรมร่วมกันและพื้นที่การรับประทานอาหารมากกว่าพื้นที่ของมหาลัย เช่น หอสมุด

### **ข้อเสนอแนะ**

จากข้อค้นพบและข้อมูลเชิงลึกข้างต้น โครงงานนี้มีข้อเสนอแนะเชิงนโยบายแก่ทางมหาวิทยาลัยเพื่อนำไปพัฒนาสิ่งอำนวยความสะดวกให้ตอบโจทย์นักศึกษาอย่างมีประสิทธิภาพ 3 ด้าน ดังนี้

**1. การปรับปรุงคุณภาพบริการขั้นพื้นฐาน** 

1.1 ) มหาวิทยาลัยไม่ควรใช้เกณฑ์จำนวนผู้เข้าใช้งานเป็นตัวชี้วัดความสำเร็จของบริการเพียงอย่างเดียว แต่ควรยกระดับคุณภาพการให้บริการรถ NGV และโรงอาหารส่วนกลางอย่างเป็นรูปธรรม 

1.2 ) ควรให้ความสำคัญกับการซ่อมบำรุงรักษาและกระจายโครงสร้างพื้นฐานเดิมให้ทั่วถึง เช่น ระบบปรับอากาศและปลั๊กไฟ ซึ่งคุ้มค่าและตอบสนองความต้องการของนักศึกษาได้

**2. การบริหารจัดการแบบยืดหยุ่นตามสถานการณ์** 

2.1 ) นำมาตรการเชิงรุกมาใช้เพื่อแก้ปัญหาความแออัดในชั่วโมงเร่งด่วน เช่น การขยายเวลาเปิดให้บริการพื้นที่อ่านหนังสือเป็น 24 ชั่วโมงในช่วงสอบ หรือการเพิ่มความถี่ของรถขนส่งมวลชนในช่วงเวลาเร่งด่วน

2.2 ) ปรับเปลี่ยนรูปแบบการออกแบบพื้นที่ในอนาคตให้เป็นพื้นที่อเนกประสงค์ที่ลดความเป็นทางการลง โดยผสมการเรียนรู้ การทำงานกลุ่ม และการพักผ่อนด้วยกัน แทนการใช้โครงสร้างสำเร็จรูปแบบเดียวกันทุกคณะ

**3. ข้อเสนอแนะสำหรับการศึกษาในอนาคต**

3.1 ) เนื่องจากโครงงานครั้งนี้เป็นการศึกษาเชิงสำรวจเบื้องต้นที่มีกลุ่มตัวอย่างขนาดเล็ก จำนวน 35 คน การศึกษาครั้งต่อไปควรขยายขนาดกลุ่มตัวอย่างให้มากขึ้น เพื่อให้เป็นตัวแทนของนักศึกษาทุกกลุ่มคณะได้อย่างแม่นยำ

3.2 ) ควรจัดเก็บข้อมูลเชิงเวลาด้วย เพื่อนำมาวิเคราะห์พฤติกรรมการใช้งานในแต่ละช่วงเวลาของวัน ซึ่งจะช่วยให้การวางแผนบริหารจัดการพื้นที่ได้มีความแม่นยำยิ่งขึ้น
